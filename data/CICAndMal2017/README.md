# CICAndMal2017 (Android Malware Dataset 2017)

> ⚠️ **Registration-gated.** The CIC download page serves files after a short registration form
> (name, email, institution) — the same gate as the other UNB/CIC datasets. Not an anonymous
> direct download.

**Source:** Canadian Institute for Cybersecurity (CIC), University of New Brunswick (UNB)
**Download page:** https://www.unb.ca/cic/datasets/andmal2017.html
**Paper:** Lashkari, A.H., Kadir, A.F.A., Taheri, L., Ghorbani, A.A., "Toward developing a
systematic approach to generate benchmark android malware datasets and classification," IEEE
ICCST 2018. DOI: 10.1109/CCST.2018.8585560

## What it is
Android malware dataset: captured network traffic (PCAP) plus extracted flow features (CSV) for
benign apps and malware across categories such as Adware, Ransomware, Scareware, and SMS
Malware, run on real devices. Used for Android malware detection/classification.

## Used by
- "Generalized Encrypted Traffic Classification Using Inter-Flow Signals," arXiv:2508.21558v1
  — malware classification evaluation.
