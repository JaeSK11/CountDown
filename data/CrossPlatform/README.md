## What it was
User-generated mobile-app traffic for **215 Android + 196 iOS apps** (top-100 apps across US,
China, India app stores; plus Tencent MyApps / 360 Mobile Assistant for China). Each app was
exercised 3–10 minutes with real user inputs. Used for cross-platform mobile-app classification.
